# HR-система управления сотрудниками (КЭТ им. Ф.В. Чижова)
Данный проект представляет собой полностековое веб-приложение для автоматизации работы отдела кадров. Разработан в рамках курсовой работы по дисциплине «Проектирование и дизайн информационных систем».

# Функциональность
Просмотр списка сотрудников – таблица с ФИО, должностью, отделом, статусом.

Фильтрация и поиск – по отделам, статусу, ФИО, email.

Добавление сотрудника – форма с выбором должности и отдела, образованием, контактами.

Редактирование и удаление – полное редактирование всех полей, мягкое удаление (деактивация).

Учёт отпусков – создание заявок, согласование (утверждение/отклонение), статусы.

Управление вакансиями – открытие/закрытие, отслеживание статуса.

Управление отделами – CRUD операции, автоматический подсчёт сотрудников.

Отчёты – численность по отделам, статистика отпусков по месяцам, коэффициент текучести.

Аутентификация и авторизация – JWT, роли (admin, hr, employee).

# Технологии
Бэкенд
Node.js 18+ – среда выполнения

Express.js – REST API

MySQL – база данных (через phpMyAdmin)

mysql2/promise – асинхронные запросы к БД

JWT (jsonwebtoken) – аутентификация

bcrypt – хеширование паролей

dotenv – управление переменными окружения

cors, morgan – вспомогательные middleware

# Фронтенд
React 18 – UI библиотека

Vite – сборка и dev-сервер

React Router DOM v6 – маршрутизация

Axios – HTTP-запросы, интерсепторы для токенов

React Toastify – уведомления

Tailwind CSS – стилизация (с кастомными компонентами)

Recharts – графики для отчётов

🔧 Возможные проблемы и их решение
Проблема	Решение
Ошибка подключения к БД	Проверьте, запущен ли MySQL (OpenServer). Убедитесь, что параметры в .env совпадают с реальными (порт 3306, пользователь root).
Ошибка 401 (Unauthorized)	Токен истёк или не передан. Выйдите из системы и войдите заново.
Ошибка 400 при создании сотрудника	Проверьте, что выбраны должность и отдел, заполнены все обязательные поля. Убедитесь, что personnel_number генерируется автоматически.
Отображается undefined undefined	Проблема в несоответствии camelCase/snake_case. Используйте актуальную версию фронтенда (поля firstName, lastName).
CORS ошибка	Убедитесь, что в бэкенде настроен cors() и фронтенд обращается через прокси.
Порт 5000 или 5173 занят	Завершите процесс, использующий порт, или измените порт в настройках.
